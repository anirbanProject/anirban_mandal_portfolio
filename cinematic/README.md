## 🎬 Scroll-Controlled Frame-by-Frame Scrubbing Engine

Unlike standard autoplay video players or slideshows, the background animation is **100% synchronized with the user's scroll position**:
- **299 High-Definition Frames** (`ezgif-frame-001.jpg` to `ezgif-frame-299.jpg`).
- **Initial Load**: First frame renders instantly without layout shift.
- **Scroll Down**: Frames advance in real-time matching scroll speed.
- **Scroll Stop**: The active frame freezes immediately.
- **Scroll Up**: Frames reverse smoothly back towards frame 1.
- **Progressive Preloading**: Loads initial frames first for instant interactivity, then streams remaining frames in background chunks with a top progress bar.
- **Cover Cropping**: Canvas 2D engine maintains exact aspect-ratio coverage without distortion across all viewports and mobile screens.
